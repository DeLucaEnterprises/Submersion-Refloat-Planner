# Changelog

The app version and the model version are tracked separately. Case files record both, plus an engine fingerprint, so any result can be traced to the code that produced it.

## App 1.1.1 · 2026-11-17
- Open-source release under the MIT License.
- Runs as a single standalone file (`index.html`).
- Deep-quarry example made generic.
- Engine unchanged from 1.1.0 (same fingerprint, same results).

## App 1.1.0 · 2026-11-11
- Case files (.json) and field reports (.html) that reopen in the planner.
- Opening a case reruns the model and checks the results against the saved ones.
- Settings: prepared-by name, light/dark appearance, default simulation count.
- Version history and local audit log.
- Case notes field.

## App 1.0.0 · 2026-11-11
- First release: still-water Monte Carlo model of descent, resting position and refloat.
- Verdict, key numbers, descent, refloat and gas charts, search guidance.
- Zone table updated by days with no surfacing (Bayesian search update).
- Refloat grid by depth and temperature; evidence, method and limits panels.

## Model M1.0 · 2026-10-21
- Calibrated in The Find Me Project modeling study (October 2026).
- See the README for calibration targets and validation checks.
